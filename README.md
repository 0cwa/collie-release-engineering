# Collie release engineering

Public construction, source verification and distribution tooling for [Collie](https://github.com/0cwa/collieim-android). Migration implementation is reviewed in pull requests. This repository does not contain signing keys or grant production publication authority.

See the [development cycle](docs/DEVELOPMENT-CYCLE.md) and [selected upstream sources](upstreams/README.md) for current contribution and source review workflows.

The [dual-release policy](docs/DUAL-RELEASE-POLICY.md) explains Stable candidate
promotion, the separate TrailBlazer Beta product, source activation gates,
CollieSocket compatibility, and the read-only repository protection drift report.

Older release tools and migration contracts are available at the
[`retired/release-tools` tag](https://github.com/0cwa/collie-release-engineering/tree/retired/release-tools).
