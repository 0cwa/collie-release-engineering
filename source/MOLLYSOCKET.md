# Historical MollySocket source-layer record

This note documented the MollySocket trust-context patch as a generated G/I source layer. The G/I workflow is retired; current app changes and releases follow [the development cycle](../docs/DEVELOPMENT-CYCLE.md).

The layer patch and manifest remain preserved as historical records. For the former source-layer procedure and tools, use engineering commit `d7ae1aa651009ea2dec8db76ac8f6d079e9efa62`, the last commit containing them. The retained layer test checks the frozen patch records; it does not run Android or JVM tests.
