## Important update notice

This is the last Collie release with duplicate APK filenames. Starting with the next Stable release, use `collie.apk`. **Collie is Collie FOSS.** The old `collie-foss.apk` and `collie.apk` contain the same 100% free and open-source app, with the same package and signing key.

**Using an older Obtainium configuration?** Change the APK filter to `^collie\.apk$` or use the current Collie setup. You can update your existing installation in place. Collie’s App updates also checks for compatible releases and opens the official download page when an update is available. [Current Obtainium setup](https://collie.im/obtainium/)

## What’s new

- **Collie settings.** Find Story Archive, Better Search, Starred Messages, and chat archive options under Settings → Collie.
- **Passphrase lock.** Collie now shows an error when you enter the wrong unlock passphrase.
- **UnifiedPush.** Fixed MollySocket setup and push endpoint updates. Collie can now resume cleanup of a relay linked device after an interrupted unlink. Enrollment export results show the file path and cleanup warning in a dialog. Collie asks for confirmation before new relay setup, copying a relay credential, or exporting enrollment. Existing relay configurations continue refreshing.
- **Link previews.** In Settings → Chats, turn off Web link preview images to keep titles and descriptions without fetching web thumbnails.
- **Linked devices.** Copy or paste a linking code when you cannot use the camera. Collie also alerts you sooner when a device links to your account and sends a later reminder.
